# فلها 🎮

ألعاب الشلة أونلاين وأنتم بالديسكورد: سوّ روم، أرسل الرابط، والكل يدخل بالكود.

**الألعاب:** برا السالفة · مين أنا · مافيا · لو خيروك · مين الأكثر · صدّقني · ارسم وخمّن · تلفون خربان · القنبلة · إنسان حيوان جماد · مسابقة · خمّن الإيموجي · الشفرة · مقياس · قالوا الناس

- الموقع نفسه بالمجلد الرئيسي (GitHub Pages).
- الكود المصدري بمجلد `source/`: `npm install` ثم `npm run build`، وانسخ محتوى `source/dist` للمجلد الرئيسي.
- الرومات الحية تشتغل على Supabase Realtime (مشروع felha).
- القاموس العربي في لعبة القنبلة من [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (CC BY-SA 4.0).
